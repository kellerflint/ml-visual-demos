### Think it through

{% todo "Check yourself · 2–3 questions" %}
Arguable. These are the discussion if the class is running together.

What should land: missing data usually has a reason behind it; who is absent changes what your numbers are about; a small group produces unstable percentages, which calls for care in both directions.
{% endtodo %}

{% section "Do it for real", "~35 min" %}

{% todo "Name the job" %}
Before anything from the last part goes in a report, check who is actually represented in it.
{% endtodo %}

{% notebook "Notebook 4 — Check who is missing" %}
Starts from a clean copy, so you can work this part whatever happened in an earlier one.

{% todo "To build" %}
- Space for your own prompt
- Space to paste and run what comes back
- Space to write down what you checked
{% endtodo %}
{% endnotebook %}

{% checklist "How to know it worked" %}
- Every percentage has the group size next to it
- For any gap you found, check whether the smaller group is big enough to say anything
- Ask whether the pattern comes from how the data was collected or from what it describes
- Write down which explanation you cannot rule out from the file alone
{% endchecklist %}
