{% todo "Framing" %}
Two or three sentences. The point is being able to say it out loud.
{% endtodo %}

{% section "Questions", "~25 min" %}

{% todo "To write · 5–6 questions" %}
Each should need a decision explained. Draft shapes:

- A call you made that you could have made differently. What would have changed?
- Something the data left open. Who would you ask, and what exactly?
- A point where the AI made a different call than you would. Did you notice at the time?
- A number you nearly reported and then held back. What stopped you?
- One thing in this module that only a person could have done.

The last one is the whole argument. Leave it open.
{% endtodo %}

{% todo "Reveal answers" %}
For questions with a defensible answer, a reveal underneath. Generic label. For the open ones,
say plainly that several answers work and give two or three that each would.
{% endtodo %}

{% todo %}

{% endtodo %}
{% endchecklist %}
